# Snake Game (Ou jogo da cobrinha!)
# Jogo da cobrinha feito em python!
# Por: Giulia Carvalho (2021)

Olá! Esse foi um jogo da cobrinha que eu fiz para testar a biblioteca pygame em python!

O jogo só tem um mapa e um "nível", a ideia é simples:

1- você é uma cobrinha rosa, que começa como um quadradinho.
2- comidas verdes (quadradinhos verdes) aparecem aleatoriamente, ao comê-los, a cobrinha cresce
3- o jogo em si não tem um fim, pode comê-los para sempre!
4- caso bata em si mesmo, ou no limite da tela, você perde!
